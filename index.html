Help & Support

Here are the basics for using NEXUS ONE.

1. Create an account

Use the account section below to create an account with your email and a password, or sign in to an existing account.

2. Create a project

Open AI Planner, enter a name and description, then select Create and save my plan. You must be signed in to save projects online.

3. Find your projects

Open My Projects to see saved work. You can edit project details, change status, or delete a project.

4. Understand the planner

The current planner uses built-in templates, not a live AI model. Real AI integration is a future development task.

5. Account and privacy

Only use an account you control. Sign out on shared devices. Do not put passwords or sensitive personal information into project descriptions.

Need help?

If something fails, note the exact error message and which button you pressed. Never send anyone your password or secret API keys.
